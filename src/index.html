    Send

    Several people sending the same emoji in quick succession sets off Slack's "explosion"; repeat lets one client try it, and the loop keeps sending until you stop it.

    Effects are reacji with type Effect. These names come from the picker in Slack's client; which ones animate depends on Slack's feature flags.

    A GIF reaction puts the image URL in emoji with type Gif. Receivers load it directly, without Slack's image proxy.

    Sticky emoji travel as an awarenessBroadcast with field stickyEmoji. Left empty, the channel is each huddle's own, which is a guess; fill it in if Slack ignores it.
